# The Flip Flop

A tempo-synced 16-step MIDI sequencer for Windows x64 VST3 hosts.

Extract the complete VST3 bundle into your VST3 folder and rescan. Put The Flip Flop before a virtual instrument in the same REAPER track's FX chain and press Play. Each step sets a pitch or a rest, and the plugin sends MIDI on channel 1.
